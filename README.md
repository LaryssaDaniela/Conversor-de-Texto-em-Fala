# 🔊 Conversor de Texto para Voz

Um conversor de texto para voz simples e interativo construído com HTML, CSS e JavaScript.

## 🚀 Funcionalidades

- **Conversão Instantânea:** Transforma qualquer texto digitado em áudio falado.
- **Seleção de Vozes:** Permite escolher entre diferentes vozes e idiomas disponíveis no navegador.
- **Design Limpo:** Interface moderna e responsiva com gradient e ícones personalizados.

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- API: Web Speech API (SpeechSynthesis)
